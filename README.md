# Traduzione italiana del core di Foundry VTT 14

Fork non ufficiale di [foundryvtt-lang-it-it](https://gitlab.com/riccisi/foundryvtt-lang-it-it) di Simone Ricciardi. La cronologia originale e la licenza MIT sono conservate. Questa versione aggiorna il manifest e la distribuzione per Foundry VTT 14.367 o successivo nella serie 14.

La traduzione originale risale a Foundry 12: alcune stringhe introdotte nelle versioni successive restano in inglese. Il modulo non è stato provato in una sessione Foundry VTT 14; il campo `verified` resta quindi assente dal manifest.

## Installazione

Dopo la pubblicazione della release `v0.35`, incollare in Foundry il [manifest della release](https://github.com/HackANurse/foundryvtt-lang-it-it-v14/releases/latest/download/module.json). In alternativa, estrarre `translation-core-it.zip` in `Data/modules/`, ottenendo `Data/modules/translation-core-it/`.

Per il sistema dnd5e 6.0.6 usare anche il [fork della traduzione dnd5e](https://github.com/HackANurse/foundryvtt-dnd5e-lang-it-it-v14).
